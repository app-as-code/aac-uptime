# Icon source

Icons are downloaded from the homarr-labs dashboard icon collection (`homarr-labs/dashboard-icons`,
served via jsdelivr) and, for the light/dark variants, from the selfh.st icon collection
(`selfhst/icons`). No icon was drawn or modified by hand.

| File in this repo | Upstream file | Used for |
|---|---|---|
| `icon.svg` | `homarr-labs/dashboard-icons` `svg/uptime-kuma.svg` | Default |
| `icon-dark.svg` | `selfhst/icons` `svg/uptime-kuma-light.svg` | Light-colored logo for dark mode |
| `icon-light.svg` | `selfhst/icons` `svg/uptime-kuma-dark.svg` | Dark-colored logo for light backgrounds |

Download URLs:

- https://cdn.jsdelivr.net/gh/homarr-labs/dashboard-icons/svg/uptime-kuma.svg
- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/uptime-kuma-light.svg
- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/uptime-kuma-dark.svg
